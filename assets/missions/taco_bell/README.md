# Taco Bell Mission Assets

Placeholder assets for Mission 1: The Taco Bell Drop.

## Placeholder Art Strategy

All visuals in this mission are currently placeholder colored shapes:
- **Floor**: Dark gray polygon (alley ground)
- **Walls**: Gray polygons (building sides)
- **Taco Bell door**: Brown polygon with text label
- **Dumpster**: Green rectangle
- **Louis**: Blue rectangle with "Louis" label
- **Goons**: Red/brown rectangles
- **Bag**: Brown triangle shape
- **Collectibles**: White rectangle (polaroid), gold square (keychain)
- **Sniff trail**: Green dashed line
