# GdUnit4 Test Plan

Initial must-not-break tests for Taco Bell Iso and reusable mission systems:

1. Beam triggers only once.
2. Louis route actually bypasses a challenge.
3. Code gate and beam are physically separated.
4. Counters reset on restart/death.
5. Pause menu owns Objectives / Scheme Cards / Clues.
6. Poop bags become aimed tools.
7. Mission start initializes objective state.
8. Mission restart clears transient flags but preserves intended persistent progression.
9. Scheme cards unlock intended routes/items/assists.
10. Mission completion writes expected result state.
