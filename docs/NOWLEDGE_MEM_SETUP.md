# Nowledge Mem + OpenCode Setup (Windows)

This project uses Windows-native tooling for memory, implementation, debugging, planning, and cross-agent handoffs.

## Required Runtime

1. The Nowledge Mem desktop app must be running on Windows.
2. Use a private/local search index model by default for this project.
3. The local HTTP API at `http://127.0.0.1:14242` is the preferred automation path for OpenCode/Cursor handoffs.
4. OpenCode is installed on Windows for this project, not WSL.

The `nmem` CLI has been unreliable in OpenCode/Cursor wrapper paths. Do not retry `nmem` when a wrapper reports `nmem CLI not found`; use the HTTP API workaround below.

## HTTP API Workaround

- Search memories: `POST http://127.0.0.1:14242/memories/search`
- Save/upsert memory: `POST http://127.0.0.1:14242/memories`
- Update an existing memory: `PATCH http://127.0.0.1:14242/memories/{memory_id}`
- Use PowerShell `Invoke-RestMethod` with JSON generated by `ConvertTo-Json -Depth 8` or higher.
- Prefer a stable custom `id` for durable procedure/status memories so writes are idempotent.
- If new memory creation is blocked by the memory limit, patch an existing related memory instead of retrying `nmem`.

## Role Boundaries

1. OpenCode and Cursor are both implementation/debugging agents for this project.
2. `AGENTS.md` is the highest-priority repo-local source of truth for roles, workflow, scope, validation, reporting, and handoff requirements.
3. `docs/Prompt_Improvement.md` is mandatory supplemental operating context for non-trivial OpenCode and Cursor implementation/debugging work, but it defers to `AGENTS.md` on conflicts.
4. Nowledge Mem is for decisions, handoffs, debugging findings, and project memory.
5. Do not save random noise.
6. Do not use Nowledge Mem as a replacement for `AGENTS.md` or repo docs.
7. Before implementation/debugging work, search Nowledge Mem for the active phase/subsystem and inspect recent `reports/ai/` handoffs so each system can verify exactly what the other did last.
8. After implementation/debugging work, save or update a concise Nowledge Mem handoff with exact files changed, validation run, risks, and next steps.
9. Coordination happens through `AGENTS.md`, `docs/Prompt_Improvement.md`, `reports/ai`, Nowledge Mem, and copied prompts.

## What to Save in Nowledge Mem

Save concise, high-value memories for:

- architecture decisions
- debugging root causes
- final fixes
- current branch/project status
- prompt handoffs
- must-not-forget constraints

## WSL Note

WSL OpenCode is not the default for this project because Godot, Cursor, and Nowledge Mem are running on Windows.
